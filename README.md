# AI MedCare - Predictive Medical Equipment Maintenance System

AI MedCare is an advanced, interactive AI-powered web application designed to monitor, predict, and manage the health and maintenance of critical healthcare equipment (such as Ventilators, Patient Monitors, and MRI/CT Imaging Systems).

## 🚀 Features

- **Real-Time Telemetry & Sensor Dashboard**: Live tracking of key operating metrics like temperature, vibration, voltage, pressure, and operational hours.
- **Predictive Machine Learning Engine**: Instant failure probability estimates, estimated remaining useful life (RUL), and recommended maintenance schedules.
- **Interactive Predictive Analysis**: Input custom sensor readings to predict maintenance needs in real-time with visual risk indicators.
- **Equipment Inventory & Diagnostics**: Comprehensive management and telemetry history for medical devices across facility departments.
- **Maintenance Alerts & Logs**: Automated warning triggers and historical log tracking for maintenance teams.
- **Modern Responsive Interface**: Built with an interactive UI, glassmorphism visuals, real-time Chart.js telemetry charts, and mobile responsiveness.

## 🛠️ Tech Stack

- **HTML5 & CSS3**: Semantic mark-up, Tailwind CSS, custom glassmorphism, and responsive styling.
- **JavaScript (ES6+)**: Interactive UI logic, real-time sensor updates, and failure calculation algorithms.
- **Chart.js**: Dynamic real-time plotting of equipment telemetry metrics.
- **FontAwesome & Google Fonts**: Inter and JetBrains Mono typography with crisp vector iconography.
